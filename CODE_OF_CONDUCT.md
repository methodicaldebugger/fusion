Code of Conduct
Our commitment

Fusion is a community project built around the idea of connecting programming communities.

We want the Fusion community to be welcoming to people with different:

programming backgrounds
experience levels
technical opinions
languages
ecosystems
professional backgrounds

We are committed to providing a respectful environment for everyone who participates in the project.

Expected behavior

Community members are expected to:

Be respectful.
Assume good faith when possible.
Give constructive technical feedback.
Welcome newcomers.
Explain disagreements with technical reasoning.
Respect different levels of experience.
Focus criticism on ideas and code rather than people.
Be patient when discussing difficult technical problems.
Give credit to other people's work.
Respect the communities and ecosystems Fusion aims to interoperate with.

It is completely acceptable to strongly disagree about language design.

It is not acceptable to use that disagreement as an excuse to attack another person.

Unacceptable behavior

The following behavior is not acceptable:

Harassment
Personal attacks
Threats
Discrimination
Hate speech
Intimidation
Deliberate disruption
Sexual harassment
Publishing private information without permission
Trolling intended to drive people away from the project
Repeatedly derailing technical discussions
Malicious behavior toward contributors or users

Technical disagreement is welcome.

Personal abuse is not.

Technical disagreements

Fusion is a language-design project, so disagreements are inevitable.

When disagreeing with a proposal, focus on:

the problem
the proposed design
technical consequences
implementation complexity
alternatives
evidence
user experience

For example:

"I don't think this feature belongs in the language because it increases compiler complexity without providing enough benefit."

is constructive.

Whereas:

"Only an idiot would design it this way."

is not.

Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Depending on the circumstances, maintainers may:

Ask someone to stop inappropriate behavior.
Remove inappropriate content.
Temporarily restrict participation.
Remove someone from a discussion.
Ban someone from project spaces in serious or repeated cases.

Enforcement decisions will take the circumstances and severity of the behavior into account.

Reporting

If you experience or witness behavior that violates this Code of Conduct, report it privately to the project maintainers through the project's designated private communication channel.

Please include:

what happened
where it happened
when it happened
who was involved
any relevant links or evidence

Do not publicly repost private information when making a report.

Good-faith reporting

Reports should be made in good faith.

False reports intended to harass or punish another community member are themselves inappropriate.

A report made honestly about behavior that turns out not to violate this Code of Conduct will not be punished simply because the reporter misunderstood the situation.

Scope

This Code of Conduct applies to project spaces and activities associated with Fusion, including:

GitHub repositories
issue discussions
pull requests
project discussions
community channels
official Fusion events
other spaces where someone is representing the Fusion project
Final principle

Fusion exists to build bridges between communities.

Different programming languages, ecosystems, companies, universities, and open-source projects have different histories and perspectives.

We may disagree about technology.

We should still be able to work together.

Build bridges between communities.
