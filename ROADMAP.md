Vision

Fusion is an open-source programming language(currently written in rust) whose long-term goal is to connect software ecosystems instead of replacing them.

Fusion aims to provide one language and one toolchain that can gradually interoperate with existing ecosystems including Rust, C, C++, Java, C#, Go, Swift, Zig, and others.

The goal is knowledge interoperability, languages should not be isolated islands, developers worldwide must unite.
The goal is bridging communities, knowledge transfer, and interoperability.
Python-level entry point + Go-level conceptual discipline + Rust-inspired language features + a huge interoperability layer underneath.

Learn more about fusion and download the files at: https://fusion.ifree.page






What is Fusion?
Fusion is an experimental open-source programming language written in Rust. Its long-term goal is to make existing programming ecosystems interoperable through one language and developer experience.

What works today?
Lexer → parser → AST → type checker → interpreter.

What are we building next?
Fusion 0.2: diagnostics, language correctness, standard-library foundations, tests and documentation.
